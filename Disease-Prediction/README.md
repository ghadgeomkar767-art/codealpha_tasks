# 🩺 Disease Prediction System using Machine Learning

A Flask-based Machine Learning web application that predicts the risk of three major diseases:

- ❤️ Heart Disease
- 🩸 Diabetes
- 🎗️ Breast Cancer

The application allows users to enter medical parameters through a web interface and receive an instant prediction along with confidence score, health recommendations, and a downloadable PDF medical report.

# 🚀 Installation

Clone the repository

```bash
git clone <repository-url>
```

Move into the project folder

```bash
cd Disease-Prediction
```

Create a virtual environment

```bash
python -m venv venv
```

Activate virtual environment

### Windows

```bash
venv\Scripts\activate
```

### Linux / Mac

```bash
source venv/bin/activate
```

Install dependencies

```bash
pip install -r requirements.txt
```

---

# ▶ Running the Project

Run the Flask application

```bash
python src/app.py
```

Open your browser

```
http://127.0.0.1:5000
```

# ✅ Input Validation

Every prediction form validates user input before submission.

Examples:

- Age: 18–100 years
- Blood Pressure: 40–220 mmHg
- Cholesterol: 80–650 mg/dL
- BMI: 10–70

Invalid values are highlighted and the form cannot be submitted until corrected.
